# 🚀 VPS First Setup

Скрипт для быстрой первоначальной настройки нового VPS на базе Ubuntu.

## ✨ Возможности

- 🔄 Обновление системы
- 📦 Установка базового набора утилит
- 🔒 Настройка базовой безопасности
- 🛠️ Подготовка сервера к дальнейшему развёртыванию сервисов
- ⚡ Автоматизация рутинных действий после получения нового VPS

## 🖥️ Поддерживаемые системы

### ✅ Протестировано

- Ubuntu 22.04 LTS
- Ubuntu 24.04 LTS

### ⚠️ Возможно работает, но не тестировалось

- Debian 12+
- Другие современные Debian-based дистрибутивы

## 📋 Требования

- 👑 Пользователь `root`

или

- 🔑 Пользователь с правами `sudo`

## 🚀 Быстрый запуск

Выполните одну команду:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/vldslvshvchk/vps-first-setup/main/vps-setup.sh)
```

## ⚠️ Важное замечание

Скрипт выполняет системные изменения и предназначен для новых VPS или серверов, которые только готовятся к эксплуатации.

Перед использованием рекомендуется ознакомиться с содержимым скрипта и убедиться, что его действия соответствуют вашим требованиям.
